# Карта Игр Steam

Этот проект создает интерактивную 2D-карту игр из Steam, где положение каждой игры определяется на основе ее тегов. Проект полностью самодостаточен и не требует отдельного API-сервера.

## Особенности

- Интерактивная визуализация 161,865 игр из Steam
- Фильтрация по тегам, дате релиза, цене и количеству отзывов
- Возможность поиска и выделения конкретных игр
- Полностью автономное приложение на Streamlit

## Как запустить проект

### Локальный запуск

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Убедитесь, что файл `games_with_coords.parquet` находится в корневой директории проекта

3. Запустите приложение:

```bash
streamlit run app_modified.py
```

## Размещение на Hugging Face Spaces

1. Создайте аккаунт на [huggingface.co](https://huggingface.co/)

2. Создайте новый Space с типом "Streamlit"

3. Свяжите с репозиторием GitHub или загрузите файлы напрямую:

- `app_modified.py` - основное приложение
- `requirements.txt` - зависимости
- `games_with_coords.parquet` - файл с данными (около 18.5 MB)
- `README.md` - этот файл

4. Убедитесь, что файл `games_with_coords.parquet` находится в репозитории (может потребоваться использование Git LFS для больших файлов)

5. В настройках Space укажите `app_modified.py` как основной файл

### Примечания для Hugging Face Spaces

- Файл `games_with_coords.parquet` составляет около 18.5 MB, что укладывается в ограничения обычного Git
- Приложение использует кэширование Streamlit для оптимизации загрузки данных
- Всё приложение работает в одном файле, что упрощает развертывание
- Обратите внимание, что при первом запуске может потребоваться время для загрузки и кэширования данных

## Архитектура

Проект состоит из одного файла приложения, который:
- Загружает данные из файла `games_with_coords.parquet`
- Обрабатывает фильтры и параметры пользователя
- Визуализирует интерактивную карту игр с помощью Plotly
- Использует кэширование для оптимизации производительности
